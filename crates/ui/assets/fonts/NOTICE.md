# Bundled fonts

These are Zed's default UI and code fonts, copied from Zed's
`assets/fonts` at revision `f0d896f`. Zed's `.ZedSans` aliases IBM Plex Sans
and `.ZedMono` aliases Lilex.

- `ibm-plex-sans`: IBM Plex Sans, © 2017 IBM Corp., SIL Open Font License 1.1.
  See `ibm-plex-sans/license.txt`.
- `lilex`: Lilex, © 2019 The Lilex Project Authors, SIL Open Font License 1.1.
  See `lilex/OFL.txt`.

The OFL allows bundling the fonts with software. Keep each license file next
to its fonts.
